# CycleCare: Menstrual Health Awareness and Empowerment

## About the Project
CycleCare is a student project designed to improve menstrual health awareness through simple educational content, hygiene guidance, and a basic period date estimator.

## Problem Statement
Many girls and women face barriers to reliable menstrual health information, affordable hygiene products, and proper sanitation. Stigma and misinformation can make it difficult to access support.

## Features
- Menstrual health education
- Menstrual hygiene awareness
- Period date estimation
- General guidance on when to seek medical advice

## Setup Instructions
1. Install Python 3.10 or later.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Start the application:

   `streamlit run app.py`

## Testing
Run the automated tests with:

`python -m unittest discover -s tests -v`

## Privacy and Safety
CycleCare is an educational prototype, not a medical device. Period estimates are approximate and must not be used for contraception or diagnosis. Do not upload personal health information.
